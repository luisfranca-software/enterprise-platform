# Contributing

## Status

External code contributions are not currently accepted.

Issues may be opened for professional feedback, defect reports and
technical discussion, subject to repository moderation.

---

## Contribution Policy

This repository is a proprietary, source-available professional portfolio.
Unsolicited code contributions are not automatically authorised.

### Key Points

- Opening an issue or pull request does not grant any rights over the
  project or its intellectual property.

- No contribution may include third-party confidential information,
  proprietary code, or materials subject to non-disclosure agreements.

- Contributors must have the legal right to submit their contribution.
  Contributions derived from other projects must comply with those
  projects' licence terms.

- Acceptance of any contribution requires explicit maintainer approval.
  Submission of a pull request does not guarantee acceptance.

- Contribution terms must be reviewed before external contributions
  are enabled. A formal Contributor License Agreement (CLA) or
  equivalent may be required.

### What You Can Do

- Open issues for defect reports, architectural observations, or
  technical discussion.
- Provide feedback on documentation, architecture decisions, or
  engineering practices.
- Suggest improvements through issues (not pull requests, until
  external contributions are formally enabled).

### What You Cannot Do

- Submit pull requests with code changes (unless explicitly invited
  by the maintainer).
- Fork the repository for the purpose of distributing modified versions.
- Use the repository contents to develop competing products without
  written authorisation.

---

## Issue Guidelines

When opening an issue:

- Use a clear, descriptive title.
- Provide sufficient context for the maintainer to understand the
  observation or suggestion.
- Do not include credentials, API keys, or other sensitive information.
- Do not include personally identifiable information about third parties.
- Issues may be closed or moderated at the maintainer's discretion.
