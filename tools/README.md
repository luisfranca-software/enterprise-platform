# tools/

## Purpose

Utility scripts, developer tooling, and automation helpers that support the development workflow but are not part of the application source code.

## Allowed Artifact Types

- Shell scripts (`.sh`)
- Python utility scripts (`.py`)
- Docker utility configurations
- CI/CD helper scripts
- Linting and formatting configurations

## Prohibited Content

- Application source code (use `implementation/`)
- Architecture decision records (use `architecture/decisions/`)
- Sensitive credentials or secrets
- Production deployment scripts (use CI/CD pipelines)
