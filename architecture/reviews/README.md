# architecture/reviews/

## Purpose

Stores architecture review artifacts, including review meeting notes, compliance checklists, and sign-off records for architecture baseline milestones.

## Allowed Artifact Types

- Review summaries (`.md`)
- Compliance checklists (`.md`, `.yaml`)
- Sign-off records (`.md`)
- Supporting evidence (`.png`, `.pdf`)

## Prohibited Content

- Source code or configuration files
- Sensitive credentials or secrets
- Informal discussion threads — use version-controlled documents only
