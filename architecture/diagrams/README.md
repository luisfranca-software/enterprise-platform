# architecture/diagrams/

## Purpose

Stores architecture diagrams in source and exported formats. Diagrams illustrate system topology, component interactions, data flows, and deployment layouts.

## Allowed Artifact Types

- Diagram source files (`.drawio`, `.mermaid`, `.puml`, `.mmd`)
- Exported images (`.png`, `.svg`)
- Diagram metadata (`.json`, `.yaml`)

## Prohibited Content

- Source code or configuration files
- Text-only documentation (use `architecture/` or `docs/` instead)
- Sensitive credentials or secrets
- Large binary files (>10 MB) — link to external storage instead
