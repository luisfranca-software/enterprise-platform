# architecture/decisions/

## Purpose

Houses Architecture Decision Records (ADRs) that document significant architectural decisions, their context, and consequences.

## Allowed Artifact Types

- Markdown documents (`.md`) — ADR files following the `ADR-NNNN-title.md` naming convention

## Prohibited Content

- Source code or configuration files
- Diagrams (use `architecture/diagrams/` instead)
- Sensitive credentials or secrets
- Temporary or draft-only content
