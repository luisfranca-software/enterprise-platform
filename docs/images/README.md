# docs/images/

## Purpose

Stores images, screenshots, and visual assets used in documentation files throughout the `docs/` directory.

## Allowed Artifact Types

- Image files (`.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`)
- Diagram exports (`.png`, `.svg`)
- Screenshot captures (`.png`)

## Prohibited Content

- Source code or configuration files
- Diagram source files (use `architecture/diagrams/`)
- Sensitive credentials or secrets
- Large binary files (>10 MB) — link to external storage instead
